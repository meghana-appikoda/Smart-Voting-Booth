
# Smart Voting Booth

## Overview
The Smart Voting Booth is an Embedded Systems project developed to provide a secure and efficient electronic voting system. It allows users to cast their votes using push buttons while ensuring accurate vote counting and result display.

## Features
- Secure voting process
- One vote per voter
- Push-button based candidate selection
- LCD display for user interaction
- Automatic vote counting
- Final result display
- User-friendly interface

## Technologies Used
- Embedded C
- Arduino / Microcontroller
- LCD Display
- Push Buttons
- Embedded Systems
- Electronics

## Components Required
- Arduino Uno / ATmega328P
- 16x2 LCD Display
- Push Buttons
- Breadboard
- Jumper Wires
- Power Supply

## Working
1. Power on the system.
2. The LCD displays the voting instructions.
3. The voter selects a candidate using the corresponding push button.
4. The vote is recorded successfully.
5. The vote count is updated automatically.
6. After voting ends, the final results are displayed on the LCD.
